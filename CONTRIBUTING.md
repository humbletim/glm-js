# Contributing to glm-js

Thank you for your interest in contributing to `glm-js`. This is a "source-open" project, which means that while the source code is publicly available, we are not actively seeking contributions in the form of pull requests.

## Philosophy

This project is a solo-maintained "tribute" to the C++ GLM and GLSL libraries. Its development is guided by a specific, long-term vision of API and spiritual harmony with those originals, a concept we call "GLMenetics". To maintain this focus, the development roadmap is curated by the project steward.

## How to Contribute

The best way to contribute to this project is to use it and provide feedback. If you find a bug, have a feature request, or want to share an idea, we encourage you to **open an issue** on GitHub. This allows for a discussion that can help inform the project's direction.

While we are not accepting pull requests at this time, you are strongly encouraged to fork this repository, experiment with the code, and adapt it to your own needs.

Thank you for your understanding.
