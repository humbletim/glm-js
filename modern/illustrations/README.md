# Illustrations (Non‑Formal Examples)

This directory contains standalone, self‑contained, executable code examples designed to:

- illustrate specific usage patterns,
- confirm complex logic visually, or
- stage side‑by‑side comparisons of different code generations.

Key principles

- NO external dependencies — Files here must not participate in `package.json` or rely on dependencies outside of the core `../modern/` library (GLM‑JS).
- Standalone — Each YYYY‑prefixed folder is a complete, run‑on‑its‑own construct.
- Low maintenance — These are functional examples, not formally maintained test assets. Official unit tests live in `../tests/` and staging comparisons live in `../test/debates/`.
